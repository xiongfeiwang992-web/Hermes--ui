## 0. 为什么你会觉得「功能差很多」

`dj-browser`（未来家）**不是**一整套中介业务都写在本地 exe 里。

| 层级 | 是什么 | 功能在哪 | 本地样本覆盖 |
|------|--------|----------|--------------|
| **A. 桌面客户端** | Electron 专用浏览器壳 | `未来家.exe` + `main.jsc` + `set.ini` | **可完整静态盘点** |
| **B. 云端 ERP** | 房产中介管理系统（网页） | 登录后的 `dingjianerp` | **本地无业务代码** |
| **C. 多端配套** | 小程序 / 网站 / 微站 / APP | 与 ERP 同一账号与数据 | 仅域名/入口痕迹 |

```text
┌──────────────────────────────────────────────────┐
│  未来家.exe（桌面壳）[L1]                          │
│  许可/指纹/多标签/下载/更新/截图/快捷键/DNS/通知…   │
│           │ http://command/* + BrowserView         │
│           ▼                                        │
│  鼎尖 ERP（盘客/交易/财务/人事/新房/网站…）[L2]      │
│           ├── 鼎尖小程序 / 分销小程序                │
│           ├── 网站 / 微站 / 房产营销小程序           │
│           └── 隐号/电子签/群发等增值                 │
└──────────────────────────────────────────────────┘
```

```text

                 → command 协议 / ElectronCallbackManager 互调
                 → 本机：下载目录、分区缓存、electron-store、日志
```

## A2. 启动流水线

1. `NODE_ENV` 默认 `production`；捕获 `uncaughtException` / `unhandledRejection` 后 `exit(1)`  
2. `app.js` 从双源下载 `main.jsc`（超时 30s；校验 Content-Length；`.temp` 再 rename）：  
   - 主：`https://imgcdn.dingjianyun.com/djbrowser/1000/{version}/main.jsc`  
   - 备：`https://dingjian.oss-cn-shenzhen.aliyuncs.com/djbrowser/1000/{version}/main.jsc`  
3. `require('bytenode')` → `require('../../main.jsc')`  
4. 读 `set.ini`；采集设备指纹（见 A3）  
5. 许可模式：`getCustomerByLicense`（apiNumber `701_getCustomerByLicense`）→ 得租户 URL  
6. `getBrowserID` → 拼设备参数加载主站  
7. 过滤器拦截 `getWorkbenchData`；支持 `thirdpage` 独立 partition  
8. development 时可直接 `require('./main.js')`（发布包走 jsc）
