## 0. 顶层信息架构（推荐自研菜单）

```text
工作台 / 主控台
├── 盘客
│   ├── 房源（盘源查询/维护）
│   ├── 客源（客户中心）
│   ├── 带看
│   ├── 跟进（明细/统计）
│   ├── 钥匙 / 委托 / 实勘 / 验真     ← P2+
│   └── 楼盘字典 / 盘客后台参数       ← OUT/P2
├── 交易
│   ├── 意向金
│   ├── 成交报告
│   ├── 收付款
│   ├── 交易资料 / 过户               ← P2
│   └── 业绩 / 提成 / 积分            ← 提成 MVP；积分 OUT
├── 新房（可选产品线）                ← OUT（MVP）
├── 财务                              ← OUT（仅收款流水进 MVP）
├── 人事考勤                          ← OUT（组织员工进 MVP）
├── 办公 / 流程 / 知识 / 票据         ← OUT
├── 网站 / 营销 / 小程序              ← OUT
├── 报表 / BI / 市场分析              ← P2 简报
└── 设置
    ├── 组织员工权限                  ← MVP 精简
    ├── 安全许可                      ← 壳侧；自研改本地账号
    └── 盘客/交易参数后台             ← P2（MVP 写死规则）
```

## 1. 盘客管理

### 1.1 楼盘字典 `OUT`

| 菜单/能力 | 要点 | 自研 |
|-----------|------|------|
| 楼盘库 | 400+ 城 / 50 万+ 楼盘；到房号面积朝向 | OUT（手填小区） |
| 业务区域过滤 | 公司业务区域限制位置筛选项 | P2 |
| 关注小区 | 小程序 | OUT |
| 防重盘错盘 | 字典关联 | OUT |

### 1.2 盘源查询 / 盘源维护 `MVP 子集`

| 菜单/能力 | 要点 | 自研 |
|-----------|------|------|
| 盘源列表查询 | 租售、区域/地铁/学校、户型(含单房)、价格面积、关键字 | MVP 简筛 |
| 地图找房 | APP/PC | OUT |
| 盘源详情 | 图片/户型/视频/全景；相关角色人 | MVP 基础字段 |
| 角色人 | 登记/接盘/实勘/核验/摄影师/户型人；保护期 | MVP：登记+接盘 |
| 保密盘/锁定盘 | 持有上限租售分开；小程序可查 | MVP：保密盘 |
| 暂缓/恢复 | 恢复可改接盘人 | MVP：暂缓 |
| 改盘 / 重新放盘 | 类型变更审核；刷新登记人参数 | OUT |
| 收藏盘 | 装修/单价/登记日筛选 | OUT |
| 钥匙 | 登记密码；作废/归还/外界；变动提醒；编号重复策略 | OUT |
| 委托 | 电子/纸质；线上委托 | OUT |
| 实勘/空看 | 列表详情；同步外勤打卡 | OUT |
| 验真 | 状态规则；自动转盘可按验真 | OUT |
| 转成交 | 内部/外界；部门级/公司级权限拆分 | MVP：仅内部成交单 |
| 共享盘 | 小程序共享菜单 | OUT |
| 业主相关盘 | 同业主多盘 | P2 |
| 批量设置 | 合作人、实勘人 | OUT |
| 盘源导入关联 | 批次+楼盘/栋/房号模糊关联+建栋 | OUT |
| 橱窗海报打印 | 含盘源编号 | OUT |
| 图片删除原因 | 删图必填原因 | P2 |
| 强制跟进 | 看重要信息/拨号强制跟进 | P2 |
| 自动转盘 | 组织范围：不含/含/纯下级 | OUT |
| 非接盘人带看提醒 | 参数开关 | P2 |

### 1.3 客户中心 `MVP 子集`

| 菜单/能力 | 要点 | 自研 |
|-----------|------|------|
| 私客/公客 | 认领、转公；转私提醒原登记人 | MVP |
| 客户等级 | A/B/C；可自动按带看跟进划分 | MVP 手工 |
| 查重合并 | 联系人/跟进/匹配/带看/报备合并 | MVP：查重提示 |
| 保密客 | 转成交自动解密 | P2 |
| 暂缓客上限 | 参数 | OUT |
| 跟进「修改」类型 | 编辑信息也记跟进 | P2 |
| 关键字作废客 | 次数+关键字自动作废 | OUT |
| 匹配盘源 | 房客互配 | P2 |
| 多联系人 | 背景/意向 | MVP：单联系人 |

### 1.4 带看 / 跟进 `MVP`

| 菜单/能力 | 要点 | 自研 |
|-----------|------|------|
| 带看单 | 主看/陪看；单/多联系人；上传视频 | MVP：主看+结果；无视频 |
| 转有效/无效 | 可备注 | MVP：用 feedback 枚举 |
| 带看查看权限 | 个人/下级/全盘 | MVP：本人/本店 |
| 跟进明细 | 盘/客/其他；改底价统计 | MVP：盘+客 |
| 跟进统计 | 排序、到场客数穿透 | P2 |
| 实勘统计 | 表头排序 | OUT |

### 1.5 盘客后台（参数）`P2 / OUT`

大量开关：必录项、角色保护、持有上限、转盘规则、强制跟进、不刷新最后跟进时间的类型等。  
**自研 MVP：规则写死在代码/配置文件，不做可视化参数后台。**

## 12. 如何升级到「截图级菜单名」

1. 用自有许可登录未来家 → 展开左侧全部菜单  
2. 按本文件章节顺序截图或导出菜单文本  
3. 把真实菜单名填入「租户实测」列（可另开 `ERP菜单-租户实测.md`）  
4. 字段级再拆到 [`MVP需求规格.md`](./MVP需求规格.md) 各实体表  

无登录时，**本文件 + 说明书 B 部已是公开资料下的最细粒度**。
