## 3. 提成规则 ⚠️ 最容易返工，必填

**3.1 公司留存比例**

- 公司留存 ______ %，经纪人池 ______ %（默认 50 / 50）

**3.2 计提时点**（这条决定「我的提成」页面显示的钱是什么钱）

- [ ] **审批通过即计提**（成交单批了就算经纪人应得，哪怕钱还没收到）
- [ ] **收款到账才计提**（客户付多少，按比例计提多少）
- [ ] 收款满 ______ % 后一次性全额计提

**3.3 多经纪人分成**

- [ ] 默认均分（2 人各 50%，3 人各 33.33%）
- [ ] 每单手填比例（合计必须 100%）
- [ ] 固定角色分成：接盘人 ___% / 带看人 ___% / 成交人 ___%

**3.4 阶梯提成**

- [ ] 不做阶梯，统一比例（**推荐，MVP 就这么定**）
- [ ] 要阶梯：月业绩 ≤ ______ 元按 ___%；超过按 ___%

**3.5 店长/老板管理奖**

- [ ] 不做（推荐）
- [ ] 店长拿本店总佣的 ___%
