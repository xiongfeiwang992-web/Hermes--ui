# 实现状态与外部依赖

本文件记录 MASTER-2.1 在自研代码中的交付状态。这里的“完成”指本地业务闭环可录入、查询、流转、审批、消息、审计和自动验收；不代表已经购买或开通第三方商业服务。

## 已完成：门店主链路

- 自有账号、四角色、门店和数据范围
- 房源、客源、公私客、保密盘、电话脱敏
- 跟进、待跟进、带看
- 成交提交、审批、驳回
- 收款、意向金、提成
- 工作台、站内消息、审计日志、经营报表

## 已完成：盘客和交易深化

- 自建楼盘字典
- 钥匙登记、借还、作废
- 实勘、空看、验真
- 多联系人、客源合并、房源匹配
- 可配置自动掉公，默认关闭
- 合同、贷款、缴税、过户、交房节点
- 房源委托、锁定、合作、媒体、拍卖和包销记录
- 贷款、成交投诉、更名和资料清单

## 已完成：扩展业务通用流程层

| 业务域 | 本地能力 |
|---|---|
| 新房 | 项目、报备、到场、分销公司、销售报告 |
| 财务 | 收入、支出、报销、资产、凭证、薪酬 |
| 人事 | 岗位职级、调动、离职交接、考勤、请假、招聘、人事合同、工资条 |
| 办公 | 公告、知识、考试、活动、会签、票据、总结、同事圈、来电记录 |
| 营销 | 官网内容、在线委托、商机、营销活动 |
| 租赁托管 | 托管物业、租约、租金账单、维修、保洁 |
| 客关 | 投诉、诉讼、满意度问卷、回访 |
| 绩效 | 积分、管理奖、利润分红、业绩目标 |

上述扩展模块统一提供持久化、状态机、审批、权限、消息与审计，避免只做静态菜单或假数据。它们是可继续配置字段和规则的本地流程层，并不等同于原厂每个专项模块多年积累的全部行业字段、第三方渠道和财务会计细则。

当前已进一步专项落地的细节包括：房源物业类型/交易模式与查重提示、陪看人多选、成交本地附件、审计筛选导出。供应商级总账、自动更新分发、移动端独立客户端等仍须单独产品化和上线验收，不能仅凭通用流程记录宣称完成。

## 已完成：系统和桌面能力

- 功能权限开关
- 业务黑名单（原值哈希，界面脱敏）
- 密码哈希、修改密码和会话失效
- SQLite 在线备份
- Electron 截图、缩放、全屏和清缓存
- UTF-8 BOM CSV 导出

## 第三方适配器

以下能力已提供配置边界，默认关闭；启用时强制 HTTPS，并只保存密钥管理器引用，不保存明文密钥：

- CA 电子签
- 运营商真隐号和录音
- 外网房源平台
- 地图
- 微信
- 短信

要形成真实外部闭环，仍须业务方合法签约、取得 API 文档和凭据，然后实现对应供应商适配器并完成联调验收。没有第三方合同和凭据时，不伪造成功结果。

## 永不实现

- 厂商 License、许可号、主机分机和设备指纹云校验
- 厂商闭源包、jsc 热更和 command 协议仿造
- License 绕过、破解、危险提权
- 未获授权的网签或外部平台爬取
