# 未来家本地 · 自研房产中介系统（MVP）

基于文档包 **MASTER-2.1** 从零实现的门店主链路系统。  
技术栈：**Electron + TypeScript + SQLite**（业务内核可脱离 Electron，经 HTTP 调用）。

## 已确认生意口径（默认）

- 业态：二手买卖 + 住宅租赁
- 角色：管理员 / 店长 / 经纪人 / 财务
- 成交审批：店长审本店
- 提成：公司留存 50% / 经纪人池 50%；审批后计提；分成合计 100%
- 公私客：不自动掉公；经纪人见本人私客 + 本店公客
- 保密盘：接盘人 + 店长 + 管理员
- 跨店：完全隔离

## 红线

禁止厂商许可 / 指纹云校验 / License 绕过 / 拷贝厂商安装包。

## 快速开始

```bash
npm install
npm run seed          # 写入演示账号与门店
npm run smoke         # 主路径自动化验收
npm run dev:server    # API :8787
npm run dev:renderer  # UI  :5173
```

浏览器打开 `http://127.0.0.1:5173` 即可演示（无需 Electron）。

一键开发（需本机图形环境）：

```bash
npm run dev
```

## MVP 主路径

登录 → 录房源 → 录客源 → 写跟进 → 登记带看 → 提交成交 → 店长审批 → 财务收款 → 查看提成

另含：工作台摘要、站内消息、审计日志、电话脱敏、店隔离/私客/保密盘。

## P2 第一批

- 薄自建楼盘字典
- 钥匙登记、借出、归还和作废
- 实勘/空看记录
- 房源验真提交与店长审核
- 客源按意图和预算匹配在售房源
- 意向金登记、退款及冲抵已审批成交单

运行完整健康检查：

```bash
npm run health
```

该命令依次执行 MVP 与 P2 主路径自动化验收。

## P2 第二批

- 客户多联系人与重复客源合并
- 可配置未跟进自动掉公（默认关闭）
- 合同、贷款、缴税、过户、交房节点跟踪
- 月度经营指标与经纪人业绩排行
- UTF-8 BOM 成交报表 CSV 导出

## 扩展业务流程套件

已继续实现房源/交易扩展、新房分销（含分销公司与销售报告）、财务、人事、办公、营销、租赁托管、客关和积分分红，统一支持状态机、审批、消息、权限与审计。离职交接已专项化，支持房源、客源、钥匙和房源角色预览与事务性交接，完成后立即停用账号和会话。费用报销已专项化，支持员工申请、费用票据、店长审批、财务付款和付款凭证，并强制申请、审批、付款职责分离。考勤请假已专项化，支持上下班打卡、迟到早退判定、带原因修正、请假时段防重和分级审批。简易收支已专项化，支持门店现金账、成交关联、凭证、作废、期间汇总和 CSV 导出。岗位调动已专项化，支持职级、员工定级、调动审批和原店业务资产事务性交接。招聘已专项化，支持岗位、候选人防重、简历、筛选面试、Offer 和一键转员工账号。员工合同已专项化，支持签署附件、启用、续签、到期、终止和合同履历。薪酬已专项化，支持薪资档案、月度计算、财务调整、管理员审批、财务发薪和员工工资条。公告与知识库已专项化，支持公司/门店范围、草稿发布归档、置顶、版本留痕、附件、阅读回执和未读统计。租赁托管已专项化，支持托管合同、租约、周期账单、逾期刷新、财务收租以及维修保洁工单。客户关怀已专项化，支持投诉、诉讼、处理凭证、满意度调查、客户回访、超期和闭环履历。营销线索已专项化，支持本地活动、线索分配跟进、转客源、在线委托受理，以及商机黑名单拦截。积分分红已专项化，支持积分规则与审批、业绩目标进度、店长管理奖和按积分分配的利润分红。新房分销已深化专项化，支持本地分销公司启停导出，以及到场报备后的销售报告、合同必传、审批成交和财务结算可见性控制。成交投诉与更名已专项化，支持已审批成交的投诉调查结案凭证，以及客户/业主更名审批生效。房源扩展已专项化，支持带原因锁定、合作盘、视频全景、拍卖资料和独家/包销业态。资产台账与备查凭证已专项化，支持固定资产登记处置和借贷平衡的备查凭证过账作废。办公协同已专项化，支持考试、活动报名、流程会签、票据申领发放回收、工作总结、同事圈和来电匹配；通用业务套件入口已清空。

系统能力包括功能权限、黑名单、密码修改、数据库备份，以及 Electron 截图、全屏、缩放和清缓存。

CA 电子签、真隐号、外网平台、地图、微信和短信提供默认关闭的安全适配入口；取得合法供应商账号和凭据后再联调。详见 [`docs/实现状态与外部依赖.md`](docs/实现状态与外部依赖.md)。

这些模块提供真实持久化、状态机、审批、权限、消息与审计；专项实现状态和仍需产品化的边界见 [`docs/实现状态与外部依赖.md`](docs/实现状态与外部依赖.md)。
